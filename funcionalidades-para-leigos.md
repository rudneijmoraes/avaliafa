# Sistema de Avaliação FA - Explicado de Fácil Entendimento

## O que é o Sistema?

Imagine uma plataforma digital completa onde professores podem criar provas online, alunos podem fazer essas provas de forma segura, e tudo fica organizado em um só lugar. É como ter uma sala de aula virtual super moderna!

---

## 🎯 Para Quem Serve?

### 👩‍🏫 **Para Professores e Coordenadores**
- Crie provas sem complicação
- Veja seus alunos fazendo a prova em tempo real
- Receba relatórios detalhados do desempenho
- Emita certificados automaticamente

### 👨‍🎓 **Para Alunos**
- Faça provas de qualquer lugar com segurança
- Receba certificados digitais ao ser aprovado
- Acompanhe seu histórico de provas
- Tenha uma experiência justa e monitorada

### 🏫 **Para a Instituição**
- Tenha controle total sobre todas as avaliações
- Integre com outros sistemas educacionais
- Mantenha tudo organizado e seguro
- Tenha relatórios completos para tomada de decisão

## ✨ O Que o Sistema Faz?

### 1. **Criação de Provas Super Fácil**
- **Monte seu banco de questões**: Salve todas as perguntas que você cria e reuse-as quando quiser
- **Importe questões prontas**: Importe de CSV, XML ou direto do Prova Fácil (ZIP)
- **Organize por disciplina**: Associe disciplinas a provas e questões, crie novas disciplinas sem sair do formulário
- **Defina o tempo**: Configure quanto tempo cada aluno tem para responder
- **Veja tudo no painel**: Dashboard mostra total de provas, questões, sessões e taxa de aprovação

### 2. **Aplicação de Provas Segura**
- **Links personalizados**: Cada aluno recebe um link único e secreto para fazer a prova
- **Monitoramento inteligente**: O sistema "cuida" do aluno durante a prova
- **Anti-trapaças**: Detecta se o aluno tenta abrir outras janelas ou fazer coisas estranhas
- **Salvamento automático**: Se a internet cair, as respostas são salvas!

### 3. **Correção e Resultados**
- **Correção automática**: Para questões de múltipla escolha, a nota sai na hora
- **Relatórios detalhados**: Veja quais questões os alunos erraram mais
- **Estatísticas gráficas**: Gráficos bonitos que mostram o desempenho da turma
- **Exportação fácil**: Baixe tudo em Excel para analisar depois

### 4. **Certificados Digitais**
- **Emissão automática**: Aluno aprovado? Certificado na hora!
- **Verificação online**: Qualquer pessoa pode verificar se o certificado é verdadeiro
- **Design profissional**: Certificados com cara de instituição séria
- **Arquivo seguro**: Ninguém pode falsificar os certificados emitidos

### 5. **Gestão de Alunos**
- **Cadastro em massa**: Adicione toda uma turma de uma vez só
- **Foto de perfil automática**: No primeiro acesso à prova, o aluno tira uma foto pela webcam que fica salva no sistema
- **Histórico completo**: Veja todas as provas que cada aluno já fez
- **Integração com Moodle**: Se sua escola usa Moodle, tudo se conecta via LTI 1.3
- **Controle de acesso**: Defina quem pode acessar o quê

### 6. **Atualização Fácil do Sistema**
- **Atualize pela própria tela**: O administrador aplica atualizações fazendo upload de um arquivo ZIP
- **Backup automático**: Antes de cada atualização, o sistema cria uma cópia de segurança completa
- **Sem precisar de técnico**: Não precisa acessar o servidor — tudo é feito pela interface

## 🔒 Como o Sistema Protege as Provas?

### **Segurança de Cinema Espacial**
- **Foto de identificação**: O aluno tira uma foto no primeiro acesso — aparece no monitor, perfil e resultado
- **Biometria digital**: O sistema reconhece o computador do aluno
- **Câmera de segurança**: Tira fotos da tela durante a prova (se permitido)
- **Detetive virtual**: Identifica comportamentos suspeitos
- **Cofre digital**: Todas as informações ficam trancadas a sete chaves

### **Justiça para Todos**
- **Todos com o mesmo tempo**: O sistema controla o tempo igualmente para todos
- **Ordem aleatória**: Cada aluno recebe as questões em ordem diferente
- **Sem cola**: Impossível copiar do colega
- **Transparência total**: Tudo fica registrado para análise posterior

## 📱 Como Funciona na Prática?

### **Para o Professor**
1. **Cria a prova**: Escolhe as questões, define o tempo
2. **Publica**: Gera os links para os alunos
3. **Acompanha**: Abre o painel e vê quem está fazendo a prova
4. **Analisa**: Recebe relatórios automáticos após o término

### **Para o Aluno**
1. **Recebe o link**: Por e-mail ou mensagem
2. **Clica e começa**: Coloca seus dados e inicia a prova
3. **Responde com calma**: O sistema salva tudo automaticamente
4. **Vê o resultado**: Recebe a nota e, se aprovado, o certificado

### **Para a Coordenação**
1. **Acessa o painel**: Vê todas as provas acontecendo
2. **Monitora**: Identifica qualquer problema em tempo real
3. **Relatórios**: Recebe análises completas sobre tudo
4. **Decisões**: Usa os dados para melhorar o ensino
